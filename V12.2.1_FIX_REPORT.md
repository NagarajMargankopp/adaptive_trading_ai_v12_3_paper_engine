# V12.2.1 Fix Report

## Observed failure

V12.2 successfully fetched the 400-bar warmup for all five assets, but the first live finalized candle callback raised:

`TypeError: '<' not supported between instances of 'str' and 'Timestamp'`

The failure occurred when sorting a history DataFrame after appending the finalized live candle.

## Root cause

REST warmup rows use pandas UTC timestamps. `CandleStore.to_dict()` serializes finalized candle timestamps as ISO strings. Appending the live dictionary therefore created a mixed-type `timestamp` column.

## Correction

`run_v12_live_signal.py` now:

1. Converts the incoming finalized timestamp to UTC `pandas.Timestamp` immediately.
2. Converts existing history timestamps to UTC before comparison.
3. Uses `pd.concat()` instead of the deprecated/private `_append()` method.
4. Re-normalizes timestamps after concatenation before sorting.
5. Compares synchronization timestamps as normalized timestamps.

`app/v12_live_signal.py` also removes the `Series.view()` deprecation warning.
