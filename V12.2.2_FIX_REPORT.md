# V12.2.2 Fix Report

## Observed failure

The V12.2.1 live signal observer fetched the full 400-bar warmup for all five assets, but the first finalized live candle callback raised:

`NameError: name 'pd' is not defined`

## Root cause

`run_v12_live_signal.py` uses `pd.Timestamp` and `pd.to_datetime` inside `on_finalized()`, but `pandas` was not imported in that module.

## Correction

Added:

`import pandas as pd`

near the top of `run_v12_live_signal.py`.

## Verification

- `py_compile`: PASS
- Previous package test suite: 16 passed before this one-line import regression was introduced.
- Live orders remain disabled.
