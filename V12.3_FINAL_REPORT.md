# V12.3 Final Implementation Report

## Scope
V12.3 adds a live paper-position layer to the verified V12.2 live V9.3 signal observer. It does not change the V9.3 model and does not place real orders.

## Execution convention
A LONG/SHORT signal created from a completed 5-minute candle is filled at the following BTC 5-minute candle's open, with configurable adverse slippage. The default is 0.02% per side plus the existing 0.14% round-trip cost assumption.

The entry candle is not checked for exits; subsequent completed candles are checked for gap/SL/TP, then TIME exit after 12 evaluation bars. SL is used first when SL and TP are both touched inside one candle.

## Safety
- Live orders: disabled
- API credentials: not required
- Data source: public Delta REST/WebSocket only

## Validation
The V12.3 paper engine has dedicated synthetic tests for LONG take-profit, LONG stop-loss and TIME exit behavior. Run `python -m pytest -q` for the full project suite.

## Interpretation
V12.3 is designed to collect actual live paper-trade observations so that historical V11 execution assumptions can later be compared with observed feed timing, signal cadence and simulated fill behavior. It is not evidence of profitability and must remain paper-only during this stage.
