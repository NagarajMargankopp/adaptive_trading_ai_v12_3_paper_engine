# Adaptive Trading AI V9.3 — Final Price-Action Evaluation

## Purpose

V9.2.2 showed that the current causal failure-memory learner could activate, but its context-specific failure probability was not stably predictive of the next trade. The next isolated research update was therefore to add **price-action / market-structure information to the existing V8.27 ranker**, while keeping the adaptive failure intervention OFF.

This isolates one question:

> Does adding causal BTC price-action information materially change the existing V8.27 trading model's walk-forward behavior?

## Important implementation note

A first development run exposed an OHLC-index alignment mistake that caused the new price-action columns to be all missing in some folds. Those results were discarded.

The final run was rebuilt so that:

- all original V8.27 features are preserved exactly (127 features);
- the BTC OHLC series are aligned to the signal rows before price-action calculations;
- 64 new price-action / market-structure features are appended;
- the new features are tested for causality by changing a future candle and verifying that earlier feature values do not change.

The final reported numbers below are only from the corrected implementation.

- Live execution: disabled

## What was added

### Candle geometry — 9

Body size, absolute body, candle range, upper wick, lower wick, body/range, close location, wick imbalance, and gap.

### Candle-structure flags — 6

Bullish engulfing, bearish engulfing, inside bar, doji, hammer, and shooting star.

### Market structure / breakout context — 28

For 12/24/48/96 bars: position inside the prior range, distance to prior high/low, breakout-up/down state, and breakout strength.

The prior high/low thresholds are shifted by one candle, so the current candle cannot define its own breakout threshold.

### Directional structure — 18

For 12/24/48 bars: price efficiency, up fraction, higher-high fraction, higher-low fraction, lower-high fraction, and lower-low fraction.

### Range regime — 3

Current candle-range z-score over 24/48/96 bars.

## Blind reserved-future stress test

The Fold-3 model was frozen and applied to the final reserved 5% block.

- 33 trades
- 60.61% win rate
- raw net-return sum: +0.057810
- profit factor: 2.573
- maximum drawdown: -0.797%
- equity return: +5.9092%
- LONG / SHORT: 16 / 17
- TP / SL / TIME: 6 / 4 / 23
- bootstrap 95% CI for mean raw trade return: [0.000118, 0.003290]

For the matched V9.2 baseline, the same reserved block had 36 trades and +2.3363% equity return. This difference is descriptive evidence from one reserved historical block, not proof of future profitability.

## Evidence that the model actually uses price-action features

For the Fold-3 model, XGBoost feature importance assigned approximately:

- LONG model: 29.7% of normalized feature importance to the 64 new price-action features.
- SHORT model: 32.3% of normalized feature importance to the 64 new price-action features.

Among the highest-ranked price-action features were 96-bar breakout strength, distance to the previous 96-bar high/low, 12/48-bar structure measures, and 48-bar price-efficiency measures.

Feature importance shows model usage/association; it is not a causal attribution of trading profit.

## Causality check

The V9.3 test suite includes a specific future-mutation test: one future OHLC candle is modified, and all price-action feature values up to the candle immediately before that future point must remain unchanged.

Result: PASS.

## Final assessment

### V9.3 status: RESEARCH / PAPER ONLY

The corrected V9.3 implementation successfully adds price-action and market-structure information without changing the original V8.27 feature set. In this historical walk-forward experiment, the new feature layer produced positive held-out results in all three test folds and higher test aggregate trade-return statistics than the matched V9.2 baseline.

However, the evidence is still limited to the available historical walk-forward and one reserved future block. The first reserved block contains only 33 trades, and the result is not an independent guarantee of future performance.

### What should happen next

Do **not** turn the V9.2.2 failure learner back on yet. Keep the V9.3 ranker as the isolated candidate and run a separately locked evaluation of the adaptive layer on top of the richer price-action context only after the ranker itself is frozen.

That next experiment should answer:

> Does the V9.2.2 causal failure learner become more predictive when it receives the richer price-action context?

Any thresholds for that adaptive layer should be fixed from validation and then tested once on an untouched holdout. Live trading remains disabled.
